# Prompts

`writing-guide.md` is the committed system prompt for project copy. Interview questions and long-copy shape use per-category banks in that file, keyed off the category selected in the project editor. Sculpture follows Art. Related project links mark a page as a satellite so the model asks about the part instead of retelling the venue.

`sputnik.txt` is the voice sample. It is gitignored and never published to the live site.

Copy your Sputnik file to this folder as `sputnik.txt` before using Generate. The CMS returns an error if the file is missing.
