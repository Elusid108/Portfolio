About the project

Every video for the old portfolio went through someone else's site first. I fought their upload limits, waited on their load times, and then embedded a player that loaded slower than the rest of the page. One night it clicked that I could run a video converter myself, mute the audio, and host the files on GitHub next to everything else. Once I saw that, the rest was a no-brainer.

The result is a content management system that lives entirely on my laptop. I drop a video into the editor and a local server catches it, strips the audio, encodes it to 1080p, and drops it into the right project folder. Images get converted to WebP the same way. The front end reads from a single JSON block, so updating a project feels about as fast as moving files around on the desktop. When I hit publish, the server compiles the text and media into one HTML file. It takes under ten seconds.

Pushing that folder to GitHub Pages puts the site live. There is no hosting bill, no upload cap, and no third-party player. The site you are reading came out of it.
