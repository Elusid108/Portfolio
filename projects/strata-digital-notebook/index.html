Strata - Digital Notebook

OneNote's notebook structure, an infinite canvas, and a code editor that runs what you write. Every file lives in your own Google Drive.

About the project

The number of files flying around at work on a normal day is overwhelming. Boston Dynamics runs on the Google ecosystem, so it was Docs, Sheets, Slides, links, and snippets of code, and I kept losing track of all of it. My system was native Drive sorting plus a bookmark folder tree, and the bookmark tree had stopped working as a system some time before I admitted it.

Strata is what I built to hold it. I took the three-tier structure of OneNote (notebooks, tabs, pages) as the skeleton, then added block pages for structure and an infinite canvas for the things that do not fit in a page. The piece I use most is a split-screen editor that runs the code you write in it, so a specialized calculator can live right next to the notes that explain it. The one wall I hit was embedding other websites. Almost every site refuses to load inside an iframe, so that became a page of shortcut links instead.

Every file stays in the user's own Google Drive. Sign in with a Google account and it is yours. It is how I keep track of my job now.
