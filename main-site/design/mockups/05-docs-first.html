Getting started

PixelDecode & PixelPilot

Open hardware for driving addressable pixels from a network stream. A PixelDecode board decodes Art-Net, sACN or DDP on an ESP32-S3 and drives the pixels directly. PixelPilot, on a Raspberry Pi, discovers boards, schedules shows and pushes firmware. PixelPilot Desktop maps pixels from a photo and previews live.

Get the board
PXD-8 · 8 outputs · 4,096 px · $89

Quickstart

Power the board, join the PXD-xxxx access point it broadcasts, and set your Wi-Fi. Then point any Art-Net or sACN source at it. From a terminal on the same network:

# find every PixelDecode board on the LAN
$ pxd discover
PXD-8    192.168.1.42   pxd-fw 1.4.2   8 outputs   idle
PXD-16   192.168.1.43   pxd-fw 1.4.2   16 outputs  art-net u0–u15

# configure output 0: 512 × WS2812B, GRB, universe 0
$ pxd set 192.168.1.42 out0 --type ws2812b --count 512 --order grb --universe 0

No CLI? The same settings are in the board's web UI at http://pxd-xxxx.local.

Power & wiring

Budget 60 mA per WS2812B pixel at full white, or about 20 mA for typical content. Inject power every 100–150 pixels at 5 V. Every output on a PixelDecode board is fused at 5 A and level-shifted to 5 V; data-line length to the first pixel should stay under 2 m without a buffer.

Hardware reference

Three PixelDecode boards share one firmware and one configuration model. They differ in output count, network and power.

PixelPilot HAT

A HAT for the Raspberry Pi 4/5 with an RTC, a status OLED and two user buttons, plus an SD image running PixelPilot OS. Boot it, open http://pixelpilot.local, and every PixelDecode board on the network appears. $69

Firmware releases

Every board ships with the latest pxd-fw. Update over the air from PixelPilot, or from a browser with the web installer.

Web installer

Connect the board over USB-C, open the installer in Chrome or Edge, and pick the target. The manifest is signed and pinned to a release SHA-256.
